# Warriors Journey 🎮

**Warriors Journey** is a 2D pixel-style action game and my first game-development project.

The project is being developed as a learning experience, with new levels, mechanics, and improvements planned for future versions.

## 🕹️ About the Game

- 2D pixel-style action gameplay
- Currently includes **2 playable levels**
- Platforming and exploration
- Enemies and combat elements
- Collectibles
- Background music and sound effects
- Built with **Godot**

## 📥 Download & Play

**Windows:** [Download Warriors Journey v2.0.0](../../releases/tag/v2.0.0)
